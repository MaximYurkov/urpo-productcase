# Product Methods

В системе используются базовые продуктовые фреймворки.

## JTBD

Формат:

Когда [ситуация],
я хочу [действие или мотивация],
чтобы [ожидаемый результат].

JTBD описывает задачу пользователя, а не просто функцию продукта.

## Lean Canvas

Основные блоки:

- Problem
- Customer Segments
- Unique Value Proposition
- Solution
- Channels
- Revenue Streams
- Cost Structure
- Key Metrics
- Unfair Advantage

## Backlog

Backlog описывается через:

- Epic
- User Story
- Acceptance Criteria
- Priority

Формат User Story:

Как [роль],
я хочу [действие],
чтобы [ценность].

## Roadmap

Roadmap показывает развитие продукта по этапам:

- MVP
- первая версия
- улучшения
- возможные интеграции
