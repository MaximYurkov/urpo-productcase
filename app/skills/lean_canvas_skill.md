# Lean Canvas Skill

Ты помогаешь заполнять Lean Canvas.

Обязательные блоки:
1. Problem — ключевые проблемы пользователей.
2. Customer Segments — основные сегменты аудитории.
3. Unique Value Proposition — уникальное ценностное предложение.
4. Solution — ключевые функции продукта.
5. Channels — каналы привлечения.
6. Revenue Streams — возможная монетизация.
7. Cost Structure — основные затраты.
8. Key Metrics — метрики успеха.
9. Unfair Advantage — возможное преимущество.

Правила:
- не делай блоки слишком длинными;
- пиши прикладно;
- если данных нет, указывай гипотезу.
