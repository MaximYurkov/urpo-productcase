# ProductCase AI Report

## 1. Идея продукта
AI-сервис для автоматического подбора рекламных креативов для малого бизнеса.

## 2. Проблема пользователя
Пользователь не может найти подходящие рекламные креативы для своих товаров или услуг.

## 3. Целевая аудитория
Предприниматели, малые предприятия.

## 4. User Persona
- **Имя:** Иван Петрович
- **Возраст:** 35 лет
- **Профессия:** Предприниматель
- **Занятость:** Работает в малом бизнесе
- **Образ жизни:** Живет в городе, работает с компьютером и использует социальные сети

## 5. JTBD (Job Story)
**Когда:** Пользователь загружает описание товара или услуги на свой страницу в ВКонтакте или Яндекс Директ.

**Я хочу:** Запросить автоматическое подбор рекламных креативов, чтобы быстро найти подходящие идеи для продвижения своего бизнеса.

**Чтобы:** Пользователь может легко и эффективно расширять свою аудиторию на платформах ВКонтакте и Яндекс Директ, используя автоматически подобранные рекламные креативы. Это позволяет ему увеличить продажи и улучшить маркетинговый результат.

## 7. Lean Canvas (Fill in the Lean Canvas)
**1. Problem:** Какая проблема решает этот продукт?

- Проблема: Малый бизнес не может найти подходящие рекламные креативы для своих товаров или услуг.

**2. Customer Segments:** Кто будет использовать этот продукт?

- Целевая аудитория: Предприниматели, малые предприятия.

**3. Unique Value Proposition (UVP):** Какой ценности предлагает этот продукт?

- UVP: Помогает пользователям быстро находить подходящие рекламные креативы для своих товаров или услуг, решая проблему несуществующих рекламных креативов.

**4. Solution:** Ключевые функции продукта

- Система предлагает идеи баннеров, тексты объявлений и рекомендации по аудитории для рекламы во ВКонтакте и Яндекс Директ.

**5. Channels:** Каналы привлечения

- Продукт будет использоваться через платформы ВКонтакте и Яндекс Директ, где пользователи загружают описание товаров или услуг.

**6. Revenue Streams:** Монетизация продукта

- Возможно, монетизация может быть достигнута через оплату за использование сервиса или партнерские программы с рекламодателями.

**7. Cost Structure:** Основные затраты

- Затраты могут включать разработку и поддержку системы, а также маркетинговые кампании для привлечения пользователей.

**8. Key Metrics:** Метрики успеха

- Ключевые метрики: количество использований продукта, количество продаж, рост числа подписчиков на платформах ВКонтакте и Яндекс Директ.

**9. Unfair Advantage:** Возможное преимущество

- Возможно, этот продукт будет иметь преимущества по сравнению с конкурентами, так как он автоматизирует процесс подбора рекламных креативов, что позволяет пользователям节省 время и улучшает результаты продаж.
